# Portfolio — Bartłomiej Białobrzewski

A simple portfolio website (HTML, CSS, JavaScript) prepared to showcase frontend skills and links to projects.

## How to run locally
1. Open the directory in VSCode.
2. Install the Live Server extension and click "Go Live" or open `index.html` in any browser.
3. (Optional) If you use TypeScript: `npm init -y && npm i -D typescript && npx tsc --init` and run `npx tsc`.

## Deployment (quick options)
- **GitHub Pages**: push the repository, in settings enable GitHub Pages from the `main` branch → `/root`.
- **Netlify**: drag and drop the folder with the generated `index.html` file or connect the repository for auto-deploy.
- **Vercel**: connect the repository and deploy (works by default with static).
